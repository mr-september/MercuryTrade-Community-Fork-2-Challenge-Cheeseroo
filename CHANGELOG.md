# Changelog

All notable changes to MercuryTrade Community Fork 2: Challenge Cheeseroo will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.7.0] - 2026-03-30

### Added
- Comprehensive CodeQL security analysis integration with GitHub Actions
- Automated vulnerability scanning in CI/CD pipeline
- Java 8 compatibility improvements for Maven compiler plugin
- Multi-module version resolution fixes for Maven builds
- Parent POM resolution enhancements
- GitHub Actions build failure fixes

### Fixed
- CodeQL GitHub Actions workflow failures
- Java 8 compatibility issues in Maven compiler plugin
- Maven multi-module version resolution problems
- Parent POM resolution errors
- GitHub Actions build failures

### Changed
- Repository structure cleanup and temporary file removal
- Updated .gitignore with comprehensive patterns for internal documents and logs
- Enhanced build automation documentation

## [1.6.2] - 2025-10-11

### Fixed
- Cleaned up repository structure and removed temporary files
- Removed internal planning documents from version control

## [1.6.1] - 2025-10-11

### Added
- Comprehensive documentation of CodeQL fixes
- Security vulnerability remediation documentation

## [1.6.0] - 2025-08-04

### Added
- Auto-scaling feature with display detection and scaling recommendations
- Placeholder graphics replacement
- Enhanced UI scaling metrics classes
- EDT (Event Dispatch Thread) safety improvements
- Defensive copies and null-safe map access for configuration services
- Default backfilling for scale configuration
- Unknown-key fallback behavior for configuration services
- Focused app-core tests for configuration contracts

### Fixed
- CodeQL GitHub Actions failures
- Java 8 compatibility issues
- Maven multi-module version resolution
- Parent POM resolution issues
- GitHub Actions build failures

### Changed
- Refactored UI scaling with centralized metrics classes
- Hardened EDT safety for UI mutations using SwingUtilities
- Normalized dependency management across modules
- Improved configuration service robustness
